# Troubleshooting and important reminders

## The LET Attendance tab is not visible

In the Admin Requests Teams channel, check the tabs at the top of the posts. If LET Attendance (D) is not visible, select the plus sign (`+`) and look through the available tabs.

## I cannot find the save option

Some screens offer additional actions in the navigation sidebar. For Drop-ins, the **Save Records** button appears after selecting an area and date. If there were no attendees, the app displays **No Attendance** instead.

## I added a row, but my data is not saved

Adding or copying a row does not save the register. Select **Save Records** in the sidebar. The source manual notes that partially completed registers can be saved and continued later.

## I need to change or remove a workshop

Select the workshop in the table and choose **View/Edit** in the sidebar. Use **Update Record** to save changes. **Delete Record** permanently removes the workshop and cannot be undone, according to the source manual.

## I am maintaining courses or topics

Use **Tools**, then choose **View/Edit Courses** or **View/Edit Topics**. Check your selection before using **Remove**, because the source manual does not describe a recovery process.

## Accessibility and data protection

- Images on this public site are recreated mock-ups using fictional values.
- Do not add real student records, personal data, internal links or original unredacted screenshots to this public repository.
- Published alt text is written to describe the safe replacement illustration accurately. See `ALT-TEXT-REGISTER.md` for the image-by-image descriptions and handling notes.
- Test the published site using keyboard-only navigation, zoom, a screen reader and automated accessibility checks.
