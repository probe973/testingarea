# Analysis

The source manual describes Analysis as under development at the time it was written. It can analyse entered data by:

- Drop-ins, Retreats or Workshops.
- The current academic year or the previous academic year.
- School or level.

## Choose analysis filters

Select the event type, academic year and whether to start with School First Analysis or Level First Analysis.

![Screenshot of Analysis filters for event type, academic year and School First Analysis or Level First Analysis.](assets/images/15-original-ui.png)

## Explore the results

After choosing the filters, the app presents a monthly attendance table for the selected event type and grouping. Select a school or level in the table to drill further into the data.

Depending on the selected route, the further breakdown can include:

- Level or school.
- Course.
- Course type.
- Location (in-person or online).
- Topic.

Select a table heading to sort in ascending order; select it again to sort in descending order.

![Screenshot of an analysis table with event tabs and columns for school, months, total and percentage. School labels and values have been replaced with fictional examples.](assets/images/16-original-ui.png)
