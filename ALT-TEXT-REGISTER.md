# Image alt-text register

The published site uses the screenshots embedded in the original LET Attendance Dashboard 4.0.0 manual. Three screenshots containing attendance/course table data (images 4, 11 and 16) retain the real interface but have their visible table values replaced with fictional examples. Other screenshots are preserved from the source manual.
